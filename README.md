# 瑞典语学习手册 · Swedish Learning Handbook

A comprehensive A2-level Swedish language reference handbook written for **Mandarin speakers**, with cross-language comparisons to English, German, and French.

An **interactive web app** (flashcards, quizzes, AI conversation practice) is available at:
> 🔗 **[Live App Demo](https://JhanXXX.github.io/Swedish_learning_handbook)**

## 互动学习工具 · Interactive App Features

The companion web app (in `app/`) includes:

- **单词卡片 Flashcards** — drill vocabulary and verb conjugations
- **填空练习 Quizzes** — test grammar rules and forms
- **全文检索 Search** — search across all chapters instantly
- **学习进度 Progress** — track what you've mastered (saved locally)
- **AI 对话练习 AI Conversation** — connect your own OpenAI / Claude / Gemini API key for adaptive conversation practice and real-time feedback

## 使用说明 · How to Use

### Read online (no setup)
Browse the `handbook/` folder above — GitHub renders the Markdown beautifully.

### Run the app locally
```bash
cd app
npm install
npm run dev
```

### Deploy your own copy
```bash
cd app
npm run deploy
```

## 关于本手册 · About

This handbook assumes you:
- Are a native or fluent **Mandarin** speaker
- Have basic familiarity with **English**
- May have some background in **German** or **French** (comparisons are made throughout)

Content covers the **A2 CEFR level** — enough to handle everyday conversations, travel, and simple written communication in Swedish.
