# 第一章：语法基础 — 语言的骨架

*Chapter 1: Grammar Foundations*

本章建立瑞典语的核心语法框架。如果你已经掌握英语，并对德语和法语有基础了解，你会发现瑞典语在很多地方与它们相似——但也有几个关键差异需要重点注意。本章先处理这些"骨架"规则，后续章节的词汇和时态都建立在这个基础上。

## 1.1 人称代词

人称代词是句子的主语或宾语，是构建任何句子的第一步。瑞典语的人称代词系统与英语高度相似，比德语和法语都更简单。

### ① 主格代词（主语位置）

主格代词用作句子主语，即动作的执行者。

|                |            |              |          |                  |
|----------------|------------|--------------|----------|------------------|
| **人称**       | **瑞典语** | **英语**     | **德语** | **法语**         |
| 我             | jag        | I            | ich      | je               |
| 你（单数）     | du         | you          | du       | tu               |
| 他             | han        | he           | er       | il               |
| 她             | hon        | she          | sie      | elle             |
| 它（en词）     | den        | it           | es       | il / elle        |
| 它（ett词）    | det        | it           | es       | il / elle        |
| det（泛指）    | det        | it / there   | es       | il (impersonnel) |
| 我们           | vi         | we           | wir      | nous             |
| 你们（复数）   | ni         | you (plural) | ihr      | vous             |
| 他们/她们/它们 | de         | they         | sie      | ils / elles      |

> *💡 jag 的 j 发/j/音（类似英语yes的y）。注意小写——瑞典语中 jag 不像英语 I 那样大写。*
>
> *💡 den 和 det 都表示"它"，选哪个取决于所指名词的genus：en词用den，ett词用det。这是瑞典语特有的区分，英语只有 it。*
>
> *💡 de（他们）口语中常发音为"dom"，书写仍是 de。*

### ② 宾格代词（宾语位置）

宾格代词用作动词的直接宾语（接受动作的人或物）。瑞典语的宾格变化极少，比德语和法语简单得多。

|           |           |              |                                   |
|-----------|-----------|--------------|-----------------------------------|
| **主格**  | **宾格**  | **英语对应** | **示例**                          |
| jag       | mig       | me           | Han ser mig.（他看见我。）        |
| du        | dig       | you          | Jag älskar dig.（我爱你。）       |
| han       | honom     | him          | Vi hjälper honom.（我们帮助他。） |
| hon       | henne     | her          | De känner henne.（他们认识她。）  |
| den / det | den / det | it           | Jag tar den.（我拿它。）          |
| vi        | oss       | us           | Han ser oss.（他看见我们。）      |
| ni        | er        | you          | Jag hör er.（我听见你们。）       |
| de        | dem       | them         | Vi möter dem.（我们见到他们。）   |

> *💡 与法语相比，瑞典语宾格代词放在动词之后（与英语相同），而非动词之前（法语：Je te vois → 瑞典语：Jag ser dig）。*
>
> *⚠️ 德语有四格变化（ich/mich/mir/meiner），法语有直接宾语/间接宾语区分（me/te/le/lui）。瑞典语简化了这一系统：宾格只有一套形式，无格位区分，无间接宾语代词的单独形式。*

### ③ 反身代词

反身代词用于动作指向主语本身的情况（如"我洗我自己"）。瑞典语有一个特别简洁的反身代词：所有第三人称统一用 sig，不区分性别或单复数。

|  |  |  |  |
|----|----|----|----|
| **人称** | **反身代词** | **英语** | **示例** |
| jag | mig（同宾格） | myself | Jag tvättar mig.（我洗澡。） |
| du | dig（同宾格） | yourself | Du sätter dig.（你坐下。） |
| han/hon/den/det | sig | himself/herself/itself | Hon klär på sig.（她穿衣服。） |
| vi | oss（同宾格） | ourselves | Vi roar oss.（我们玩得开心。） |
| ni | er（同宾格） | yourselves | Ni skyndar er.（你们快点。） |
| de | sig | themselves | De hjälper sig.（他们自助。） |

> *💡 sig 是瑞典语特有的第三人称统一反身代词，相当于德语的 sich——法语则需要区分 se / soi。英语没有完全对应的形式，closest是 himself/herself/itself/themselves。*

### ④ 关于"间接宾语"

你在法语中熟悉的间接宾语代词（lui, leur, me, te…）在瑞典语里没有独立的代词形式。间接宾语通常通过介词 till（给）、för（为/对）或 åt（为/替）加普通宾格代词来表达：

> **Jag ger boken till honom.**
>
> （我把书给他。 / *I give the book to him.*）
>
> *→ 到 till + 宾格 honom，没有专门的间接宾语代词形式*
>
> **Hon berättar det för mig.**
>
> （她告诉我这件事。 / *She tells me about it.*）
>
> *→ för + 宾格 mig，对应法语 me dit*
>
> *💡 部分动词可以直接跟双宾语而不用介词：Jag ger dig boken.（我给你书。）—— 此时 dig 是间接宾语，boken 是直接宾语，语序与英语相同。*

## 1.2 冠词系统

冠词是瑞典语中与英/德/法差异最大的一个点。理解冠词系统，必须先掌握一个核心概念：genus（词性）。

### ① Genus：通性（en）与中性（ett）

瑞典语名词分为两类——通性（utrum）和中性（neutrum）——分别以 en 和 ett 作为不定冠词标记。这不同于法语/德语的阴/阳性，也没有法语那样可从词尾预测性别的规律，需要逐词记忆。不过有一些统计规律可以参考：

- 约 75–80% 的瑞典语名词是 en 词（通性）

- 人物、动物、职业类名词多为 en 词

- -ing 结尾的名词通常是 en 词（en tidning 一份报纸）

- -ande / -ende 结尾的名词通常是 ett 词（ett leende 一个微笑）

- 部分抽象概念和物质名词为 ett 词，需逐词记忆

> *⚠️ Genus 不是语法格位的标记（不像德语四格），而是名词的固有属性，影响冠词、形容词变格和代词选择。务必在记忆新词时同步记住它是 en 词还是 ett 词。*

### ② 不定冠词（a/an 的对应）

不定冠词用于泛指、第一次提及，或说"某一个"的情况，与英语 a/an 功能相同。

|  |  |  |  |
|----|----|----|----|
| **Genus** | **不定冠词** | **英语** | **示例** |
| 通性（utrum） | en | a / an | en bil（一辆车）/ en dag（一天） |
| 中性（neutrum） | ett | a / an | ett hus（一座房子）/ ett barn（一个孩子） |
| 复数（任何genus） | 无冠词 | some（可省略） | bilar（一些车）/ hus（一些房子） |

> **Jag ser en hund.**
>
> （我看见一只狗。 / *I see a dog.*）
>
> *→ hund 是 en 词，用 en*
>
> **Hon köper ett äpple.**
>
> （她买了一个苹果。 / *She buys an apple.*）
>
> *→ äpple 是 ett 词，用 ett*
>
> **Vi har bilar.**
>
> （我们有车。（泛指多辆） / *We have cars.*）
>
> *→ 复数不用冠词，与英语相同*
>
> *💡 与德语相比，瑞典语不定冠词不随格位变化（德语：ein / einen / einem / eines）。瑞典语永远只是 en 或 ett，大幅简化。*

### ③ 定冠词（the 的对应）——后缀形式

这是瑞典语最独特的地方：定冠词不是独立的词（不像英语 the、法语 le/la、德语 der/die/das），而是作为后缀附着在名词末尾。

|  |  |  |
|----|----|----|
| **形式** | **后缀规则** | **示例（不定→定）** |
| en词单数 | 词尾加 -en（辅音结尾）或 -n（元音结尾） | bil → bilen（那辆车）/ dag → dagen（那天） |
| ett词单数 | 词尾加 -et（辅音结尾）或 -t（元音结尾） | hus → huset（那座房子）/ äpple → äpplet（那个苹果） |
| 通性复数 | 词尾加 -na（多数情况） | bilar → bilarna（那些车） |
| 中性复数 | 词尾加 -en 或 -na（视变格组） | hus → husen（那些房子） |

> **Bilen är röd.**
>
> （那辆车是红色的。 / *The car is red.*）
>
> *→ bil（en词）+ -en → bilen*
>
> **Huset är stort.**
>
> （那座房子很大。 / *The house is big.*）
>
> *→ hus（ett词）+ -et → huset*
>
> **Barnen leker.**
>
> （孩子们在玩耍。 / *The children are playing.*）
>
> *→ barn（ett词）复数 barn + -en → barnen*
>
> *💡 英语说 "the car"，瑞典语说 "bil-en"——定冠词的信息被"焊"在名词上了。这对初学者是最需要适应的点。*
>
> *💡 法语定冠词 le/la/les 是独立前置词；德语 der/die/das 也是前置词且随格位变化。瑞典语后置后缀的方式是北欧语言的共同特征。*
>
> *⚠️ 注意：当名词前有形容词时，不用后缀定冠词，而用独立前置定冠词 den/det/de + 形容词 + 名词。例如：den röda bilen（那辆红色的车）。这个规则在第三章形容词部分详细讲解。*

## 1.3 语序规则

语序是瑞典语语法的核心骨架之一。掌握几条主要规则，就能造出结构正确的句子。

### ① V2 规则：动词永远在第二位

这是瑞典语（和德语）最重要的语序规则：在主句中，动词必须是句子的第二个成分（第二位），无论第一位是什么。英语没有这个规则；德语有。

|                        |                    |                       |
|------------------------|--------------------|-----------------------|
| **第一位（任何成分）** | **第二位（动词）** | **其余部分**          |
| Jag（我）              | äter（吃）         | lunch.（午饭）        |
| Igår（昨天）           | åt（吃了）         | jag lunch.（我午饭）  |
| Nu（现在）             | äter（吃）         | han.（他）            |
| Ofta（经常）           | äter（吃）         | vi ute.（我们在外面） |

> **Jag äter lunch.**
>
> （我吃午饭。 / *I eat lunch.*）
>
> *→ 正常语序：主语-动词-宾语*
>
> **Igår åt jag lunch.**
>
> （昨天我吃了午饭。 / *Yesterday I ate lunch.*）
>
> *→ Igår（时间副词）提前→主谓倒装，动词åt在第二位*
>
> **Nu arbetar hon hemma.**
>
> （现在她在家工作。 / *Now she works at home.*）
>
> *→ Nu提前→倒装，arbetar在第二位*
>
> *💡 英语可以说 "Yesterday I ate lunch"，主语依然在动词前，无需倒装。瑞典语和德语一样，一旦有其他成分提前，主谓必须倒装。*
>
> *💡 "第二位"指的是第二个语法成分，不是第二个单词。例如 "Igår kväll"（昨天晚上）是一个时间状语，算一个成分，动词在它之后。*

### ② 一般疑问句：动词提前到第一位

构成一般疑问句（是/否问题）时，将动词移到句首，主语紧随其后。与英语借助 do/does 不同，瑞典语直接将动词提前，更接近德语。

> **Äter du lunch?**
>
> （你吃午饭吗？ / *Do you eat lunch?*）
>
> *→ 动词 äter 移至句首，无需助动词（对比英语 do you eat）*
>
> **Bor hon i Stockholm?**
>
> （她住在斯德哥尔摩吗？ / *Does she live in Stockholm?*）
>
> *→ 动词 bor 提前*
>
> **Har ni en bil?**
>
> （你们有车吗？ / *Do you have a car?*）
>
> *→ 动词 har 提前*
>
> *💡 法语也有类似的倒装疑问句形式（Parlez-vous français?），但法语口语常用 est-ce que 避免倒装。瑞典语口语也用这个直接倒装形式，没有 est-ce que 的等价物。*

### ③ 特殊疑问句：疑问词 + 动词 + 主语

带疑问词的问句（what, where, when…）结构为：疑问词（第一位）+ 动词（第二位）+ 主语，之后接其余成分。V2规则在此依然适用。

> **Var bor du?**
>
> （你住在哪里？ / *Where do you live?*）
>
> **Vad äter han?**
>
> （他在吃什么？ / *What is he eating?*）
>
> **När kommer tåget?**
>
> （火车什么时候来？ / *When does the train arrive?*）

### ④ 否定词 inte 的位置

否定词 inte（不，相当于英语 not）在主句中放在动词之后，主语之后。

> **Jag äter inte lunch.**
>
> （我不吃午饭。 / *I do not eat lunch.*）
>
> *→ inte 紧跟在动词 äter 之后*
>
> **Hon bor inte i Stockholm.**
>
> （她不住在斯德哥尔摩。 / *She doesn't live in Stockholm.*）
>
> **Vi har inte en bil.**
>
> （我们没有车。 / *We don't have a car.*）
>
> *⚠️ 从句中否定词的位置不同！在从句里，inte 放在动词之前。这是高频错误点，详见 1.4 节。*

## 1.4 从句与复合句

瑞典语的复合句由一个主句加上一个或多个从句构成。从句由连接词（subjunktion）引导，语序规则与主句有一个关键区别。

### ① 常用从句连接词

|  |  |  |  |
|----|----|----|----|
| **连接词** | **含义** | **英语对应** | **示例** |
| att | that（宾语从句） | that | Jag vet att han kommer.（我知道他来。） |
| som | who/which/that（关系从句） | who / which / that | Mannen som bor här.（住在这里的那个男人。） |
| när | when（时间从句） | when | När jag äter, lyssnar jag på musik. |
| om | if / whether | if / whether | Jag vet inte om han kommer.（我不知道他是否来。） |
| för att | in order to / because（目的/原因） | in order to / because | Jag springer för att bli frisk.（我跑步是为了健康。） |
| men | but（并列对比） | but | Jag vill men kan inte.（我想但做不到。） |
| eller | or（并列选择） | or | Kaffe eller te?（咖啡还是茶？） |
| och | and（并列连接） | and | Hon sjunger och dansar.（她唱歌又跳舞。） |

### ② 从句的关键语序规则：inte 前移

这是主句和从句的最重要区别，也是初学者最容易出错的地方：

- 主句：动词 + inte（否定词在动词后）

- 从句：inte + 动词（否定词在动词前）

|  |  |  |
|----|----|----|
| **类型** | **结构** | **例句** |
| 主句（否定） | 主语 + 动词 + inte + 其他 | Han kommer inte.（他不来。） |
| 从句（否定） | 连接词 + 主语 + inte + 动词 + 其他 | Jag vet att han inte kommer.（我知道他不来。） |

> **Jag tror att hon inte förstår.**
>
> （我认为她不理解。 / *I think that she doesn't understand.*）
>
> *→ 从句 att + hon + inte（提前）+ förstår*
>
> **Han säger att han inte är trött.**
>
> （他说他不累。 / *He says he isn't tired.*）
>
> *→ 从句 att + han + inte + är*
>
> **Om du inte vill, behöver du inte.**
>
> （如果你不想，你不必。 / *If you don't want to, you don't have to.*）
>
> *→ om从句：inte在vill前；主句：inte在behöver后*
>
> *⚠️ 这个规则与德语类似（德语从句动词后置），但比德语略简单：瑞典语从句动词不必移到句末，只是 inte 的位置改变。*

### ③ 关系从句（som）

som 用于引导关系从句，相当于英语的 who / which / that，指代之前提到的名词。与英语不同，瑞典语 som 不能省略。

> **Det är boken som jag läste.**
>
> （这就是我读过的那本书。 / *That's the book that I read.*）
>
> *→ som 不可省略，英语中 that 可省略*
>
> **Mannen som bor bredvid oss är snäll.**
>
> （住在我们旁边的男人很友善。 / *The man who lives next to us is kind.*）
>
> *💡 英语中可以说 "the book I read"（省略 that），瑞典语必须保留 som："boken som jag läste"。*

## 1.5 疑问词

以下是瑞典语最常用的疑问词，结构均为：疑问词 + 动词 + 主语（V2规则，见1.3）。

|  |  |  |  |
|----|----|----|----|
| **疑问词** | **含义** | **英语** | **示例** |
| vad | 什么 | what | Vad gör du?（你在做什么？） |
| vem | 谁（单数） | who | Vem är det?（那是谁？） |
| vilka | 谁们（复数） | who（plural） | Vilka kommer?（谁们要来？） |
| var | 在哪里（位置） | where | Var bor du?（你住在哪里？） |
| vart | 去哪里（方向） | where（to） | Vart går du?（你去哪里？） |
| när | 什么时候 | when | När börjar filmen?（电影什么时候开始？） |
| varför | 为什么 | why | Varför skrattar du?（你为什么笑？） |
| hur | 怎么/如何 | how | Hur mår du?（你好吗？） |
| hur mycket | 多少（不可数） | how much | Hur mycket kostar det?（这要多少钱？） |
| hur många | 多少（可数） | how many | Hur många elever finns det?（有多少学生？） |
| vilken / vilket | 哪个（en/ett词） | which | Vilken film vill du se?（你想看哪部电影？） |

> *💡 var 和 vart 的区分是瑞典语特有的——var 问静态位置（在哪里），vart 问动态方向（去哪里）。英语的 where 涵盖两者，但瑞典语必须区分：Var är du?（你在哪里？）vs. Vart åker du?（你去哪里？）*
>
> *💡 vilken/vilket 需与名词的 genus 一致：vilken bil（en词）/ vilket hus（ett词）。复数统一用 vilka：vilka böcker（哪些书）。*

### 常用疑问句型

> **Hur heter du?**
>
> （你叫什么名字？ / *What is your name?（直译：你叫什么？）*）
>
> **Var kommer du ifrån?**
>
> （你从哪里来？ / *Where are you from?*）
>
> **Hur gammal är du?**
>
> （你多大了？ / *How old are you?*）
>
> **Vad kostar det?**
>
> （这个多少钱？ / *How much does this cost?*）
>
> **Varför är det så dyrt?**
>
> （为什么这么贵？ / *Why is it so expensive?*）

## 📖 综合短文：一段日常对话

*体裁：日常口语对话 · 场景：问路 · 难度：A1–A2*

本篇对话综合运用本章所学的人称代词、冠词、V2语序、疑问词和从句结构，场景真实、句式典型。

**— 对话正文 —**

> **Anna: Ursäkta, vet du var centralstationen är?**
>
> *（打扰一下，你知道中央车站在哪里吗？）/ Excuse me, do you know where the central station is?*
>
> **Erik: Ja, det vet jag! Den är inte långt härifrån.**
>
> *（是的，我知道！它离这里不远。）/ Yes, I know! It's not far from here.*
>
> **Anna: Vart ska jag gå?**
>
> *（我应该往哪里走？）/ Which way should I go?*
>
> **Erik: Du går rakt fram och tar sedan den första gatan till vänster.**
>
> *（你直走然后走第一条左边的街。）/ Go straight ahead and then take the first street on the left.*
>
> **Anna: Och hur långt är det?**
>
> *（然后有多远呢？）/ And how far is it?*
>
> **Erik: Det tar ungefär fem minuter till fots. Stationen är en stor byggnad som du inte kan missa.**
>
> *（步行大约五分钟。车站是一座你不会错过的大建筑。）/ It takes about five minutes on foot. The station is a big building that you can't miss.*
>
> **Anna: Tack så mycket! Vet du också om det finns en kiosk på vägen?**
>
> *（非常感谢！你也知道路上有没有小卖部吗？）/ Thank you so much! Do you also know if there's a kiosk on the way?*
>
> **Erik: Ja, det finns en liten kiosk precis vid hörnet. Den öppnar klockan åtta.**
>
> *（是的，路口正好有一家小的。它八点开门。）/ Yes, there's a small one right at the corner. It opens at eight.*
>
> **Anna: Perfekt! Du är mycket hjälpsam.**
>
> *（太好了！你真的很热心。）/ Perfect! You are very helpful.*
>
> **Erik: Ingen orsak. Ha en bra dag!**
>
> *（不客气，祝你今天愉快！）/ Don't mention it. Have a good day!*

**📝 语法标注**

|  |  |
|----|----|
| **对话片段** | **语法说明** |
| vet du var … är? | 从句：疑问词 var + 间接疑问语序（不倒装）→ var centralstationen är（从句语序） |
| Den är inte långt | den 指代 centralstationen（en词）；inte 在动词 är 之后（主句否定） |
| Vart ska jag gå? | vart 问方向（非位置）；ska 为情态动词（将来/意图） |
| Du går … och tar sedan | V2语序：主语 Du 在第一位，动词 går 在第二位 |
| en stor byggnad som | som 引导关系从句，不可省略（英语 that 可省） |
| om det finns en kiosk | om 引导间接疑问从句（whether there is） |
| Den öppnar klockan åtta | den 指代 kiosk（en词）；klockan åtta = at eight o'clock |
