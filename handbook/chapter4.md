# 第四章：动词大类 — 行动与生活

*Chapter 4: Verb Categories — Action & Everyday Life*

本章按语义场分类整理 A2 级最核心的动词，覆盖爱好与休闲、日常需求、行动与移动、感知与认知四大类别。每个动词给出完整的四种时态形式（不定式 / 现在时 / 过去时 / supinum），标注动词组别，并附典型搭配和例句。

> *复习提示：每个动词的四种核心形式为——不定式（词典形式）/ 现在时（日常陈述）/ 过去时（叙述过去）/ supinum（完成时：har + supinum）。动词组别（G1–G4 或不规则）可帮助你推断同组其他动词的变化规律。*

## 4.1 爱好类动词 — 运动、乐器与休闲

表达爱好时，动词选择取决于活动类型。瑞典语有几个重要的搭配规则，与英语的用法存在系统性差异，需要重点掌握。

### ① 核心搭配规则：spela / sjunga / lyssna / titta / se

以下四个动词在爱好场景中使用频率极高，搭配各有特点：

|  |  |  |  |
|----|----|----|----|
| **动词** | **核心用法** | **不能用的情况** | **示例** |
| spela | 演奏乐器 + 进行球类/棋类运动 | 不用于观看运动 | spela gitarr / spela fotboll / spela schack |
| sjunga | 唱歌（一般） | — | sjunga en visa / sjunga i kor |
| lyssna pa | 听（音乐/广播/播客） | 不用于观看 | lyssna pa musik / lyssna pa podcast |
| titta pa | 观看（电视/电影/比赛） | 不用于参与运动 | titta pa TV / titta pa en match |
| se / se pa | 看（电影/节目，较口语） | 略正式时用 titta | se en film / se pa nyheter |
| lasa | 阅读（书/报/网络） | — | lasa en bok / lasa tidningen |
| rita | 画画（线描/素描） | 不用于油画/水彩 | rita en bild / rita en karta |
| mala | 绘画（颜料类） | 不用于素描 | mala med oljefarger / mala akvarell |

> *💡 spela 覆盖乐器和球类运动两个领域，相当于英语的 play。注意：乐器前不加冠词（spela gitarr，不是 \*spela en gitarr），但球类运动前也不加冠词（spela fotboll）。*
>
> *💡 titta pa 和 se/se pa 的区别：titta pa 更正式，se pa 更口语，两者可互换用于看电视/电影。lyssna pa 则专门用于听，不可与 titta 混用。*

## 4.3 行动与移动类动词

移动动词在瑞典语中有细致的分类，尤其是步行（ga）、乘坐交通（aka）、跑（springa）等动词，以及方向性小品词（in/ut/upp/ner/hem 等）的搭配，构成了描述移动的完整系统。

### ① ga vs. aka vs. kora — 三种核心移动方式

|  |  |  |  |
|----|----|----|----|
| **动词** | **核心含义** | **典型搭配** | **不适用场合** |
| ga | 步行移动 / 前往（步行） | ga till skolan / ga hem / ga en promenad | 乘坐交通工具时不用 |
| aka | 乘坐交通工具移动 / 滑行 | aka buss / aka tag / aka bil / aka skidor | 步行时不用 |
| kora | 驾驶（汽车/卡车等） | kora bil / kora lastbil / kora om | 骑行/步行时不用 |
| cykla | 骑自行车 | cykla till jobbet / cykla pa en led | 不用于其他交通工具 |
| rida | 骑马 | rida en hast | 仅限骑马 |

> *ga 和 aka 的区别是瑞典语学习者最需要掌握的一对。英语的 go 可以涵盖两者（go by bus = aka buss；go on foot = ga），但瑞典语必须区分。如果你坐地铁去某地，一定用 aka，不是 ga。*

### ③ 方向性小品词 — 赋予移动方向

瑞典语中许多移动动词可以搭配方向性小品词（partiklar），构成方向明确的复合动词结构。小品词类似英语的 up/down/in/out，但位置规则略有不同：

|  |  |  |  |
|----|----|----|----|
| **小品词** | **含义** | **与 ga 搭配** | **与 komma 搭配** |
| in | 向内/进入 | ga in（进去） | komma in（进来） |
| ut | 向外/出去 | ga ut（出去） | komma ut（出来） |
| upp | 向上 | ga upp（上去/起床） | komma upp（上来） |
| ner / ned | 向下 | ga ner（下去） | komma ner（下来） |
| hem | 回家 | ga hem（走回家） | komma hem（到家） |
| bort | 离开（不回来） | ga bort（离开/去世口语） | komma bort（走丢） |
| over | 穿越/越过 | ga over（越过/穿过） | komma over（克服/越过来） |
| forbi | 路过/经过 | ga forbi（路过） | komma forbi（过来/路过） |

> **Ga in! Dorren ar oppet.**
>
> (进来吧！门是开着的。 / *Come in! The door is open.*)
>
> *-\> ga in：向内移动*
>
> **Han sprang ut ur huset.**
>
> (他跑出了房子。 / *He ran out of the house.*)
>
> *-\> springa + ut + ur（out of）*
>
> **Nar kommer du hem?**
>
> (你什么时候回家？ / *When are you coming home?*)
>
> *-\> komma hem = 到家*
>
> **Vi gick over bron till andra sidan.**
>
> (我们走过桥到了对岸。 / *We walked across the bridge to the other side.*)
>
> *ga upp 有两个常见含义：向上走（ga upp for trappan = 走上楼梯）和起床（Nar gar du upp? = 你几点起床？）。语境决定含义。*
>
> *小品词 hem（回家）vs. hemma（在家）的区分：hem 表示方向（going home），hemma 表示位置（being at home）。Jag gar hem（我回家）vs. Jag ar hemma（我在家）。*

### 感知动词的关键区分

瑞典语中，听和看各有两个动词，用法区别与英语 hear/listen 和 see/look/watch 高度对应：

|  |  |  |
|----|----|----|
| **动词对** | **被动感知（无意识）** | **主动感知（有意识）** |
| 看 | se（看见，强调结果）：Jag ser ett berg.（我看见一座山。） | titta pa（注视/观看）：Titta pa mig!（看我！） |
| 听 | hora（听见，强调结果）：Jag hor musik.（我听见音乐。） | lyssna pa（聆听）：Lyssna pa vad jag sager.（听我说。） |

> *💡 这组区分与英语完全平行：see/hear = 被动感知，look/watch/listen = 主动感知。法语也有类似区分：voir/voir vs. regarder；entendre vs. ecouter。*

### 认知动词关键辨析：tycka / tro / mena

这三个动词都可以译为"认为"，但用法有重要区别：

|  |  |  |  |
|----|----|----|----|
| **动词** | **用法侧重** | **典型句式** | **示例** |
| tycka（om） | 主观喜好/感受/看法（个人体验性判断） | Jag tycker att... | Jag tycker att filmen ar bra.（我觉得电影很好。） |
| tro | 主观推测/信念（不确定，基于推断） | Jag tror att... | Jag tror att han kommer.（我猜他会来。） |
| mena | 意思是/表达意图（说话者想表达的含义） | Vad menar du? | Vad menar du med det?（你这话是什么意思？） |

> **Jag tycker att det ar for varmt har.**
>
> (我觉得这里太热了。 / *I think it's too hot here.*)
>
> *-\> tycka att = 主观感受性判断*
>
> **Jag tror att det ska regna imorgon.**
>
> (我觉得明天会下雨。 / *I think it will rain tomorrow.*)
>
> *-\> tro att = 基于推测的判断，不确定*
>
> **Vad menar du nar du sager det?**
>
> (你说这话是什么意思？ / *What do you mean when you say that?*)
>
> *-\> mena = 表达含义*
>
> **Jag kommer inte ihag hennes namn.**
>
> (我想不起来她的名字了。 / *I can't remember her name.*)
>
> *-\> komma ihag（可分动词）：否定句中 inte 在 ihag 之前*

### ③ 表达意见的固定句式

以下是日常对话中表达意见、赞同、反对的常用句式：

|                           |                      |                             |
|---------------------------|----------------------|-----------------------------|
| **句式**                  | **中文**             | **英文**                    |
| Jag tycker att...         | 我认为……（主观意见） | I think that...             |
| Jag tror att...           | 我觉得……（推测）     | I believe / I think that... |
| Jag haaller med dig.      | 我同意你的意见。     | I agree with you.           |
| Jag haaller inte med.     | 我不同意。           | I disagree.                 |
| Det beror pa.             | 这取决于情况。       | It depends.                 |
| Jag ar inte saker pa det. | 我不确定这一点。     | I'm not sure about that.    |
| Enligt mig...             | 在我看来……           | In my opinion...            |
| Det verkar som att...     | 看起来好像……         | It seems like...            |

## 📖 综合短文：一篇周末活动短文

*体裁：口语化叙述短文 · 场景：描述上周末的活动 · 难度：A2（时态综合）*

本篇短文综合运用本章四类动词（爱好 / 需求 / 行动 / 感知认知），以 preteritum 为主要时态叙述上周末，并自然穿插 perfekt 和 presens，体现时态在真实叙述中的配合方式。

**— 短文正文 —**

> **I helgen hade jag en riktigt bra tid.**
>
> (这个周末我过得非常愉快。 / *This weekend I had a really good time.*)
>
> **Pa lordagen vaknade jag tidigt, ungefar klockan atta.**
>
> (周六我醒得很早，大约八点。 / *On Saturday I woke up early, around eight o'clock.*)
>
> **Jag drack kaffe och at frukost hemma, sedan gick jag ut for en morgonjoggnig.**
>
> (我在家喝了咖啡、吃了早饭，然后出去晨跑。 / *I drank coffee and had breakfast at home, then went out for a morning run.*)
>
> **Det var kallt men soligt — precis det vader jag tycker om.**
>
> (天气很冷但阳光明媚——正好是我喜欢的天气。 / *It was cold but sunny — exactly the weather I like.*)
>
> **Pa eftermiddagen spelade jag fotboll med nagra vanner i parken.**
>
> (下午我和几个朋友在公园踢足球。 / *In the afternoon I played football with some friends in the park.*)
>
> **Vi spelade i tva timmar och jag tyckte att det var jattet roligt, aven om vi forlorade.**
>
> (我们踢了两个小时，我觉得超级好玩，虽然我们输了。 / *We played for two hours and I thought it was great fun, even though we lost.*)
>
> **Pa kvallen lagade jag och min rumskompis middag tillsammans.**
>
> (晚上我和我的室友一起做了晚饭。 / *In the evening my flatmate and I cooked dinner together.*)
>
> **Vi stekte kyckling och kokade ris — det smakade fantastiskt.**
>
> (我们煎了鸡肉，煮了米饭——味道好极了。 / *We fried chicken and cooked rice — it tasted fantastic.*)
>
> **Sedan satt vi och lyssnade pa musik och pratade lange.**
>
> (之后我们坐着听音乐，聊了很久。 / *Then we sat and listened to music and talked for a long time.*)
>
> **Pa sundagen sov jag langre — jag vaknade forst klockan elva.**
>
> (周日我睡得更晚——直到十一点才醒。 / *On Sunday I slept longer — I didn't wake up until eleven.*)
>
> **Pa eftermiddagen akte jag in till stan och tittade pa en utstaallning pa ett museum.**
>
> (下午我坐车进城，在一个博物馆看了一个展览。 / *In the afternoon I took the train into town and saw an exhibition at a museum.*)
>
> **Jag har aldrig sett sa vackra tavlor tidigare — det var verkligen en upplevelse.**
>
> (我以前从没见过这么美丽的画——这真的是一段难忘的体验。 / *I had never seen such beautiful paintings before — it was truly an experience.*)
>
> **Nu ar det mandag igen och jag gar snart till jobbet.**
>
> (现在又是周一了，我马上要去上班了。 / *Now it's Monday again and I'm about to head to work.*)
>
> **Men jag vet redan att naasta helg ska jag aka skridskor med min syster.**
>
> (但我已经知道下个周末要和我妹妹/姐姐去溜冰。 / *But I already know that next weekend I'm going ice skating with my sister.*)

**📝 语法标注**

|  |  |
|----|----|
| **短文片段** | **语法说明** |
| vaknade / drack / at / gick / spelade / lagade | 全部为 preteritum（叙述过去周末事件） |
| gick ut for en morgonjogging | ga + ut（方向小品词）= 出去；for en jogging = 去跑步（for + 目的名词） |
| precis det vader jag tycker om | 关系从句：vader（名词）+ 省略 som（非正式）+ jag tycker om；tycker om 可分 |
| aven om vi forlorade | aven om = even though（让步从句） |
| satt vi och lyssnade pa musik och pratade | 动词并列：satt / lyssnade / pratade 三个动作并联，vi 共享主语 |
| sov jag langre — vaknade forst klockan elva | forst（才/直到）+ 时间 = not until...；比较级 langre（lange 的比较级） |
| akte jag in till stan | aka + in（方向）+ till stan（到市中心）；stan = staden 的口语缩写 |
| Jag har aldrig sett sa vackra tavlor tidigare | perfekt + aldrig + tidigare（以前）= 人生经历的否定；sett = se 的 supinum |
| naasta helg ska jag aka skridskor | ska + aka skridskor（将来计划）；naasta helg 提前 -\> V2 倒装 |
