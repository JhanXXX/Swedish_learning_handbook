# 第二章：时态系统 — 动词的时间维度

*Chapter 2: Tense & Verb System*

瑞典语的时态系统比法语简单得多，却比英语更规律。最大的好消息是：动词不随人称变化——所有人称用同一个动词形式，这一点彻底消除了法语和德语里最繁琐的变位表。本章先讲动词分组规律，再逐一介绍五种核心时态，最后整理最重要的不规则动词和情态动词。

> *💡 核心提醒：瑞典语动词不随人称变化。jag äter / du äter / han äter——全部相同。对比法语：je mange / tu manges / il mange，或英语：I eat / he eats（第三人称单数加-s）。瑞典语完全没有这类变化。*

## 2.1 动词分组概览

瑞典语规则动词按过去时的构成方式分为四组（Group 1–4）。掌握分组规律，就能推断大多数动词的所有时态形式，无需逐一死记。每组的核心特征是其不定式（infinitiv）词尾和过去时（preteritum）变化方式。

|  |  |  |  |  |
|----|----|----|----|----|
| **组别** | **不定式特征** | **现在时（presens）** | **过去时（preteritum）** | **动词示例** |
| Group 1 | 词根元音长，词尾 -a | 词根 + -ar | 词根 + -ade | tala（说）→ talar / talade |
| Group 2a | 词根元音长，词尾辅音 | 词根 + -er | 词根 + -de | läsa（读）→ läser / läste \* |
| Group 2b | 词根元音短，词尾辅音 | 词根 + -er | 词根 + -de（双写辅音） | stänga（关）→ stänger / stängde |
| Group 3 | 词根元音长，词尾 -r/-dd/-mm等 | 词根 + -r | 词根 + -dde | bo（住）→ bor / bodde |
| Group 4（强变化） | 无固定词尾规律 | 词根 + -er 或变化 | 元音变换（Ablaut） | skriva（写）→ skriver / skrev |

> *Group 1 是最大的一组，也是最规则的——如果你遇到一个不认识的动词，猜它是 Group 1 的概率最高。新造词（借词）通常也归入 Group 1：googla → googlar / googlade。*
>
> *Group 4（强变化动词）类似英语的不规则动词（write/wrote）和德语的强变化动词（schreiben/schrieb），靠元音变换表示时态，需要单独记忆。*
>
> *Group 2a 的过去时看似是"词根 + -de"，但实际词形因词根结尾而略有变化（如 läsa → läste，而非 \*läsde）。这些变体在2.3节过去时中详细说明。*

## 2.2 现在时（Presens）

现在时用于描述当前状态、习惯性动作、以及（在口语中）表达近期将来的计划。构成规则非常简单：不定式词尾 -a 去掉后，加上现在时后缀。

### ① 构成规则

|  |  |  |
|----|----|----|
| **动词组** | **构成方式** | **示例** |
| Group 1 | 词根 + -ar | tala（说）→ talar；köpa（买）→ köpar |
| Group 2 | 词根 + -er | läsa（读）→ läser；stänga（关）→ stänger |
| Group 3 | 词根 + -r | bo（住）→ bor；sy（缝）→ syr |
| Group 4（强变化） | 词根（有时元音变化）+ -er | skriva（写）→ skriver；komma→ kommer |
| 不规则 | 须单独记忆 | vara→ är；ha→ har；gå→ går；se→ ser |

### ② 用法

- 当前正在发生的动作（瑞典语无独立进行时，现在时兼任）

- 习惯性、反复性的动作

- 客观事实、普遍规律

- 口语中表示近期确定的计划（相当于英语 going to）

> **Jag läser en bok.**
>
> （我在读一本书。 / *I am reading a book.*）
>
> *→ 现在时兼任进行时，无需 is reading 的结构*
>
> **Hon arbetar på ett café varje dag.**
>
> （她每天在一家咖啡馆工作。 / *She works at a café every day.*）
>
> *→ 习惯性动作*
>
> **Vi åker till Göteborg imorgon.**
>
> （我们明天去哥德堡。 / *We're going to Gothenburg tomorrow.*）
>
> *→ 现在时表近期计划，imorgon（明天）提供时间参照*
>
> *💡 英语区分 "I read"（习惯）和 "I am reading"（进行）；法语区分 je lis 和 je suis en train de lire。瑞典语用同一个现在时形式覆盖两种含义，语境决定解读。*

## 2.3 过去时（Preteritum）

过去时用于叙述已完成的动作或过去的状态，是讲故事、描述经历时最常用的时态。相当于英语的简单过去时（I ate）和部分法语的复合过去时（j'ai mangé）用法。

### ① 规则动词过去时构成

|  |  |  |  |
|----|----|----|----|
| **动词组** | **过去时后缀** | **示例（不定式 → 过去时）** | **含义** |
| Group 1 | -ade | tala → talade；köpa → köpte \* | 说了 / 买了 |
| Group 2a（词根元音长） | -te | läsa → läste；köra → körde \*\* | 读了 / 开（车）了 |
| Group 2b（词根元音短） | -de | stänga → stängde；leva → levde | 关了 / 活着了 |
| Group 3 | -dde | bo → bodde；sy → sydde | 住了 / 缝了 |

> *💡 \* köpa（买）过去时是 köpte，不是 \*köpade——属于 Group 2a 而非 Group 1，需特别注意。\*\* 词根以浊辅音（d/g/v/等）结尾时用 -de；以清辅音（t/k/p/s等）结尾时用 -te。*

### ② Group 4（强变化）过去时——元音变换

强变化动词通过词根元音变换表达过去时，规律类似英语（sing/sang, write/wrote）和德语（schreiben/schrieb）。以下是最常用的一批：

|            |            |            |           |               |
|------------|------------|------------|-----------|---------------|
| **不定式** | **现在时** | **过去时** | **含义**  | **类比英语**  |
| skriva     | skriver    | skrev      | 写        | write / wrote |
| dricka     | dricker    | drack      | 喝        | drink / drank |
| sjunga     | sjunger    | sjöng      | 唱歌      | sing / sang   |
| sitta      | sitter     | satt       | 坐        | sit / sat     |
| ligga      | ligger     | låg        | 躺/位于   | lie / lay     |
| stå        | står       | stod       | 站        | stand / stood |
| bita       | biter      | bet        | 咬        | bite / bit    |
| finna      | finner     | fann       | 找到      | find / found  |
| flyga      | flyger     | flög       | 飞        | fly / flew    |
| hålla      | håller     | höll       | 握住/保持 | hold / held   |

### ③ 用法

> **Igår åt jag frukost klockan sju.**
>
> （昨天我七点吃了早饭。 / *Yesterday I ate breakfast at seven.*）
>
> *→ 叙述过去具体事件*
>
> **Hon bodde i Malmö i tio år.**
>
> （她在马尔默住了十年。 / *She lived in Malmö for ten years.*）
>
> *→ 过去持续状态*
>
> **Barnen sjöng och dansade.**
>
> （孩子们唱歌跳舞。 / *The children sang and danced.*）
>
> *→ 过去发生的动作，强变化动词*
>
> *💡 法语有复合过去时（passé composé：j'ai mangé）和未完成过去时（imparfait：je mangeais）的区分。瑞典语的 preteritum 相当于两者的综合——上下文决定是"吃了一次"还是"一直在吃"。*

## 2.4 完成时（Perfekt）

完成时表达"到目前为止已经发生"的动作，强调与现在的关联，而非某个过去的具体时间点。结构与英语现在完成时完全一致：har（have的对应）+ 动词的supinum形式。

### ① 构成：har + supinum

Supinum 是专门用于完成时的动词形式，不同于过去时。各组的 supinum 构成如下：

|  |  |  |
|----|----|----|
| **动词组** | **Supinum 后缀** | **示例（不定式 → supinum）** |
| Group 1 | -at | tala → talat；köpa → köpt |
| Group 2a/b | -t | läsa → läst；stänga → stängt |
| Group 3 | -tt | bo → bott；sy → sytt |
| Group 4（强变化） | 元音变换 + -it | skriva → skrivit；dricka → druckit；komma → kommit |
| 不规则 | 须记忆 | vara → varit；ha → haft；gå → gått；se → sett |

### ② 用法：与 preteritum 的区别

- Perfekt：强调结果或与现在的关联（已经...），不指明具体过去时间

- Preteritum：叙述某个过去时间点发生的事，常与 igår（昨天）、i förra veckan（上周）等时间副词连用

|  |  |  |
|----|----|----|
| **时态** | **例句** | **含义侧重** |
| Perfekt | Jag har ätit lunch. | 我已经吃过午饭了。（所以现在不饿） |
| Preteritum | Jag åt lunch klockan tolv. | 我十二点吃了午饭。（叙述过去事件） |
| Perfekt | Hon har rest till Japan. | 她去过日本。（人生经历） |
| Preteritum | Hon reste till Japan förra året. | 她去年去了日本。（具体时间点） |

> **Har du sett den filmen?**
>
> （你看过那部电影吗？ / *Have you seen that film?*）
>
> *→ 经历询问，不指定时间*
>
> **Jag har just kommit hem.**
>
> （我刚刚到家。 / *I have just arrived home.*）
>
> *→ just（刚刚）常与perfekt连用*
>
> **Vi har bott här i fem år.**
>
> （我们已经在这里住了五年了。 / *We have lived here for five years.*）
>
> *→ 持续到现在的状态*
>
> *💡 这个区分与英语的 simple past vs. present perfect 几乎完全对应。法语的 passé composé 在功能上更接近瑞典语的 preteritum（叙事），而非 perfekt。*
>
> *⚠️ 口语中，许多瑞典人会用 preteritum 代替 perfekt，两者边界有所模糊。但写作和正式场合仍应区分。*

## 2.5 将来时表达

瑞典语没有独立的将来时态词尾，而是用三种常见方式表达将来，各有侧重：

|  |  |  |  |
|----|----|----|----|
| **结构** | **语感/侧重** | **英语对应** | **示例** |
| ska + 不定式 | 意图、计划、决定（主观将来） | will / going to（有意图） | Jag ska resa till Stockholm.（我打算去斯德哥尔摩。） |
| kommer att + 不定式 | 预测、推断（客观将来） | will（预测） | Det kommer att regna imorgon.（明天将会下雨。） |
| tänker + 不定式 | 个人打算（较口语化） | I'm thinking of / planning to | Jag tänker studera ikväll.（我打算今晚学习。） |
| 现在时 + 时间副词 | 近期确定计划（口语常用） | I'm going to / Present continuous | Vi åker till Göteborg imorgon.（我们明天去哥德堡。） |

> **Jag ska köpa en ny cykel.**
>
> （我要买一辆新自行车。 / *I'm going to buy a new bike.*）
>
> *→ ska = 有意图的将来计划*
>
> **Det kommer att bli kallt i kväll.**
>
> （今晚将会很冷。 / *It will be cold tonight.*）
>
> *→ kommer att = 客观预测，无主观意图*
>
> **Jag tänker inte gå dit.**
>
> （我不打算去那里。 / *I'm not planning to go there.*）
>
> *→ tänker + inte = 否定打算*
>
> *💡 ska 和 kommer att 的区别类似英语 "I'm going to do it"（我决定了）vs. "It will rain"（客观预测）。德语用 werden 覆盖两者，法语用 futur simple 或 futur proche（aller + infinitif）。*

## 2.6 情态动词（Modala hjälpverb）

情态动词用于表达能力、许可、义务、可能性和意愿，后接动词不定式（无需 att）。瑞典语情态动词的现在时形式不规则，但过去时相对规律。

|  |  |  |  |  |
|----|----|----|----|----|
| **情态动词** | **过去时** | **核心含义** | **英语对应** | **示例** |
| kan | kunde | 能力 / 可能 | can / could | Jag kan simma.（我会游泳。） |
| ska | skulle | 意图 / 将来 / 义务 | shall / will / should | Du ska sova nu.（你现在该睡觉了。） |
| måste | måste（不变） | 必须（强义务） | must / have to | Vi måste gå nu.（我们必须走了。） |
| bör | borde | 应该（建议/道义） | should / ought to | Du bör äta mer grönsaker.（你应该多吃蔬菜。） |
| vill | ville | 想要（意愿） | want to | Jag vill ha kaffe.（我想要咖啡。） |
| får | fick | 被允许 / 可以 | may / be allowed to | Får jag öppna fönstret?（我可以开窗吗？） |
| behöver | behövde | 需要（necessity） | need to | Du behöver inte komma.（你不必来。） |

### ① 情态动词后不加 att

瑞典语情态动词后直接跟动词不定式，不需要 att（相当于英语的 to），这与德语相同：

> **Jag vill äta pizza.**
>
> （我想吃披萨。 / *I want to eat pizza.*）
>
> *→ vill 后直接跟 äta，无需 att（英语需要 to eat）*
>
> **Hon kan inte komma idag.**
>
> （她今天来不了。 / *She can't come today.*）
>
> *→ kan inte 后接 komma，否定词 inte 在情态动词后*
>
> *⚠️ att 的规则：情态动词后不用 att，但其他动词（如 vilja, hoppas, försöka 作为实意动词时）后可能需要 att + 不定式。具体情况在第四章动词大类中说明。*

### ② skulle——礼貌、假设与间接引语

skulle（ska 的过去时）在现代瑞典语中有多种用法，远超"过去意图"：

- 礼貌请求（相当于英语 would / could）

- 假设条件（如果……就……）

- 间接引语中的将来时

> **Skulle du kunna hjälpa mig?**
>
> （你能帮我吗？（礼貌请求） / *Could you help me?*）
>
> *→ skulle + kunna 构成极礼貌的请求*
>
> **Om jag hade tid, skulle jag resa.**
>
> （如果我有时间，我就会去旅行。 / *If I had time, I would travel.*）
>
> *→ 虚拟条件句：hade（过去时）+ skulle（条件结果）*
>
> **Han sa att han skulle komma.**
>
> （他说他会来的。 / *He said he would come.*）
>
> *→ 间接引语中 ska 变为 skulle（时态后移）*

## 2.7 核心不规则动词

以下动词是瑞典语使用频率最高的一批，变化形式不规则，必须逐一记忆。每个动词给出：不定式 / 现在时 / 过去时 / supinum（完成时用）四种核心形式。

> **vara — 是（be动词）**

瑞典语中最重要的动词，所有人称现在时统一用 är，比英语（am/is/are）和德语（bin/bist/ist/sind…）都简单。

|            |            |            |             |           |
|------------|------------|------------|-------------|-----------|
| **不定式** | **现在时** | **过去时** | **Supinum** | **含义**  |
| vara       | är         | var        | varit       | 是 / 存在 |

> **Jag är student.**
>
> （我是学生。 / *I am a student.*）
>
> *→ 所有人称用 är，无 am/is/are 区分*
>
> **Det var en vacker dag.**
>
> （那是美好的一天。 / *It was a beautiful day.*）
>
> *→ 过去时 var，所有人称相同*
>
> **Hon har alltid varit snäll.**
>
> （她一直是个善良的人。 / *She has always been kind.*）
>
> *→ supinum: varit*
>
> **ha — 有（have）**

|            |            |            |             |           |
|------------|------------|------------|-------------|-----------|
| **不定式** | **现在时** | **过去时** | **Supinum** | **含义**  |
| ha         | har        | hade       | haft        | 有 / 拥有 |

> **Jag har en bror.**
>
> （我有一个哥哥/弟弟。 / *I have a brother.*）
>
> **De hade inte mycket pengar.**
>
> （他们没有很多钱。 / *They didn't have much money.*）
>
> **Har du haft det bra?**
>
> （你最近过得好吗？ / *Have you been well?*）
>
> *→ haft 是 supinum，用于完成时*
>
> **gå — 走 / 去（步行）**

|            |            |            |             |                            |
|------------|------------|------------|-------------|----------------------------|
| **不定式** | **现在时** | **过去时** | **Supinum** | **含义**                   |
| gå         | går        | gick       | gått        | 走 / 步行 / 去（步行方式） |

> **Jag går till skolan varje dag.**
>
> （我每天步行去学校。 / *I walk to school every day.*）
>
> *→ gå = 步行去某处*
>
> **Vi gick på bio igår.**
>
> （我们昨天去看电影了。 / *We went to the cinema yesterday.*）
>
> *→ gå på bio = 去看电影（固定搭配）*
>
> *💡 注意区分 gå（步行）和 åka（乘交通工具移动）：gå till butiken（步行去商店）vs. åka till Stockholm（乘车/火车去斯德哥尔摩）。*
>
> **komma — 来**

|            |            |            |             |           |
|------------|------------|------------|-------------|-----------|
| **不定式** | **现在时** | **过去时** | **Supinum** | **含义**  |
| komma      | kommer     | kom        | kommit      | 来 / 到达 |

> **Tåget kommer klockan tre.**
>
> （火车三点到。 / *The train comes at three o'clock.*）
>
> **Varifrån kommer du?**
>
> （你从哪里来？ / *Where do you come from?*）
>
> **se — 看见**

|            |            |            |             |           |
|------------|------------|------------|-------------|-----------|
| **不定式** | **现在时** | **过去时** | **Supinum** | **含义**  |
| se         | ser        | såg        | sett        | 看见 / 看 |

> **Jag ser ett berg i fjärran.**
>
> （我看见远处一座山。 / *I see a mountain in the distance.*）
>
> **Har du sett mina nycklar?**
>
> （你看见我的钥匙了吗？ / *Have you seen my keys?*）
>
> *→ perfekt: har + sett（supinum）*
>
> **ta — 拿 / 取**

|            |            |            |             |                            |
|------------|------------|------------|-------------|----------------------------|
| **不定式** | **现在时** | **过去时** | **Supinum** | **含义**                   |
| ta         | tar        | tog        | tagit       | 拿 / 取 / 乘坐（交通工具） |

> **Ta bussen till centrum.**
>
> （乘公交车去市中心。 / *Take the bus to the city centre.*）
>
> *→ ta + 交通工具 = 乘坐*
>
> **Hon tog ett glas vatten.**
>
> （她拿了一杯水。 / *She took a glass of water.*）
>
> **ge — 给**

|            |            |            |              |          |
|------------|------------|------------|--------------|----------|
| **不定式** | **现在时** | **过去时** | **Supinum**  | **含义** |
| ge         | ger        | gav        | gett / givit | 给       |

> **Jag ger dig boken.**
>
> （我把书给你。 / *I give you the book.*）
>
> *→ 双宾语结构：ge + 间接宾语 + 直接宾语*
>
> **Han gav henne en blomma.**
>
> （他给了她一朵花。 / *He gave her a flower.*）
>
> **göra — 做 / 干**

|            |            |            |             |                 |
|------------|------------|------------|-------------|-----------------|
| **不定式** | **现在时** | **过去时** | **Supinum** | **含义**        |
| göra       | gör        | gjorde     | gjort       | 做 / 干（某事） |

> **Vad gör du?**
>
> （你在做什么？ / *What are you doing?*）
>
> *→ 最常用的日常问句之一*
>
> **Jag gjorde ingenting igår.**
>
> （我昨天什么都没做。 / *I did nothing yesterday.*）
>
> *→ ingenting = nothing*
>
> **veta — 知道（事实）/ känna — 认识（人/感受）**

这两个动词都可译为"知道"，但用法截然不同，类似法语的 savoir vs. connaître，或德语的 wissen vs. kennen：

|  |  |  |  |  |
|----|----|----|----|----|
| **动词** | **现在时** | **过去时** | **Supinum** | **用法** |
| veta | vet | visste | vetat | 知道某个事实、信息（接 att从句或疑问词） |
| känna | känner | kände | känt | 认识某人；感受到某事（接名词或形容词） |

> **Jag vet att han bor i Malmö.**
>
> （我知道他住在马尔默。 / *I know that he lives in Malmö.*）
>
> *→ veta + att从句 = 知道某事实*
>
> **Jag känner honom väl.**
>
> （我很了解他。 / *I know him well.*）
>
> *→ känna + 人 = 认识某人*
>
> **Jag känner mig trött.**
>
> （我感觉很累。 / *I feel tired.*）
>
> *→ känna sig + 形容词 = 感觉……*
>
> *💡 这个区分对英语母语者来说需要特别注意，因为英语 know 涵盖两者。法语母语者反而有优势：veta ≈ savoir，känna ≈ connaître。*

## 2.8 形容词转副词规则

副词修饰动词、形容词或整个句子，表达方式、程度或时间等。瑞典语中由形容词派生副词的方式非常规律，主要有三种模式：

|  |  |  |  |  |
|----|----|----|----|----|
| **派生方式** | **规则** | **形容词** | **副词** | **含义** |
| -t 后缀（最常用） | ett词形式（形容词中性形式）即为副词 | snabb（快的） | snabbt | 快地 |
| -t 后缀 | 同上 | glad（高兴的） | glatt | 高兴地 |
| -t 后缀 | 同上 | tyst（安静的） | tyst（不变） | 安静地 |
| -ligen 后缀 | 部分形容词加 -ligen | naturlig（自然的） | naturligtvis / naturligen | 当然地 / 自然地 |
| -s 后缀（少数） | 表"方式"的少数词 | dels（部分地） | — | （词汇化副词） |

> **Han springer snabbt.**
>
> （他跑得很快。 / *He runs fast.*）
>
> *→ snabb → snabbt（-t 副词）*
>
> **Hon sjunger vackert.**
>
> （她唱得很好听。 / *She sings beautifully.*）
>
> *→ vacker → vackert（形容词去-r加-t）*
>
> **Tala långsamt, tack!**
>
> （请说慢一点！ / *Please speak slowly!*）
>
> *→ långsam → långsamt*
>
> **Naturligtvis kan jag hjälpa dig.**
>
> （当然，我可以帮你。 / *Of course I can help you.*）
>
> *→ naturligtvis = naturally/of course，句首副词→V2倒装*
>
> *💡 瑞典语副词的 -t 形式与形容词的 ett词（中性）形式完全相同。这意味着你学形容词变格时，同时就学会了对应副词——一举两得。*
>
> *💡 英语副词通常加 -ly（quick → quickly），法语加 -ment（rapide → rapidement），瑞典语对应的是 -t（snabb → snabbt）。*

##  综合短文：一篇日记

*体裁：第一人称日记 · 场景：描述昨天、今天与明天的计划 · 难度：A2*

本篇日记综合运用本章三种时态（preteritum / presens / ska将来），以及情态动词和核心不规则动词，展示时态如何在真实叙述中自然切换。

**— 日记正文 —**

**Måndag den 14 oktober**

*（10月14日，星期一 / Monday, October 14th）*

> **Igår var det en lång dag.**
>
> （昨天是漫长的一天。 / *Yesterday was a long day.*）
>
> **Jag vaknade tidigt och drack en kopp kaffe innan jag gick till jobbet.**
>
> （我很早就醒来，在去上班之前喝了一杯咖啡。 / *I woke up early and drank a cup of coffee before I went to work.*）
>
> **På kontoret hade vi ett viktigt möte som varade i tre timmar.**
>
> （在办公室，我们开了一个持续了三小时的重要会议。 / *At the office we had an important meeting that lasted three hours.*）
>
> **Jag visste inte att det skulle ta så lång tid.**
>
> （我不知道会花那么长时间。 / *I didn't know it would take so long.*）
>
> **Efter mötet åt jag lunch med min kollega Erik. Vi gick till en restaurang nära kontoret.**
>
> （会后，我和同事Erik一起吃了午饭。我们走到办公室附近一家餐厅。 / *After the meeting I had lunch with my colleague Erik. We walked to a restaurant near the office.*）
>
> **Han tog fisk och jag tog pasta. Det var gott!**
>
> （他要了鱼，我要了意面。好吃极了！ / *He had the fish and I had the pasta. It was delicious!*）
>
> **Nu är klockan åtta på kvällen. Jag är trött men nöjd.**
>
> （现在是晚上八点。我虽然累，但很满足。 / *It's now eight in the evening. I'm tired but satisfied.*）
>
> **Jag har redan lagat middag och diskat.**
>
> （我已经做了晚饭，也洗了碗。 / *I have already made dinner and done the dishes.*）
>
> **Imorgon ska jag träffa min vän Lena.**
>
> （明天我要见我的朋友Lena。 / *Tomorrow I'm going to meet my friend Lena.*）
>
> **Vi ska ta tåget till Göteborg och titta på en utställning.**
>
> （我们要坐火车去哥德堡看一个展览。 / *We're going to take the train to Gothenburg and see an exhibition.*）
>
> **Jag hoppas att det kommer att bli soligt. Det brukar vara fint i Göteborg på hösten.**
>
> （我希望天气会晴朗。哥德堡秋天通常天气不错。 / *I hope it will be sunny. It's usually nice in Gothenburg in the autumn.*）
>
> **Nu ska jag sova. God natt!**
>
> （现在我要去睡觉了。晚安！ / *Now I'm going to sleep. Good night!*）

**语法标注**

|  |  |
|----|----|
| **日记片段** | **时态/语法说明** |
| Igår var det… | preteritum：vara → var；Igår（昨天）提前→倒装，var 在第二位 |
| drack / gick / åt / tog | preteritum 强变化：dricka→drack，gå→gick，äta→åt，ta→tog |
| som varade i tre timmar | som 引导关系从句；varade = varar 的 preteritum（Group 1: -ade） |
| Jag visste inte att det skulle ta | veta→visste（不规则过去时）；从句中 inte 在动词前；skulle = ska 的过去时（间接引语） |
| Jag har redan lagat / diskat | perfekt：har + supinum（lagat / diskat）；redan（已经） |
| Imorgon ska jag träffa… | ska + 不定式表将来；Imorgon 提前→倒装，ska 在第二位 |
| Det kommer att bli soligt. | kommer att + 不定式 = 客观预测将来 |
| Det brukar vara fint | brukar（通常）+ 不定式 = 习惯性动作，相当于英语 usually |
