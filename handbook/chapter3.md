# 第三章：形容词与描述 — 语言的色彩

*Chapter 3: Adjectives & Description*

形容词让语言有了温度和细节。瑞典语的形容词有一套变格规则——它们需要与所修饰名词的 genus（通性/中性）、数（单/复数）以及定/不定式保持一致。这个系统比德语的四格变化简单，但比英语（形容词完全不变）复杂一些。本章先彻底讲清变格规则，再按语义场覆盖颜色、情绪、评价三大描述性词汇类别，最后讲比较级和最高级。

> *💡 核心提醒：瑞典语形容词有三个变化维度——1) en词 vs. ett词，2) 单数 vs. 复数，3) 不定式 vs. 定式。掌握这三个维度，形容词变格就一目了然。*

## 3.1 形容词变格规则

瑞典语形容词的形式取决于它所修饰名词的三个属性：genus（en/ett）、数（单/复数）以及定/不定式。以下是完整的变格模式：

### ① 四种核心形式总览

|  |  |  |  |
|----|----|----|----|
| **形式** | **使用条件** | **后缀规则** | **示例（stor = 大）** |
| 基本形（en词，不定单数） | 修饰 en词 单数不定名词 | 原形，无变化 | en stor bil（一辆大车） |
| 中性形（ett词，不定单数） | 修饰 ett词 单数不定名词；兼作副词 | 通常加 -t | ett stort hus（一座大房子） |
| 复数形（所有复数，不定） | 修饰任何复数不定名词 | 通常加 -a | stora bilar / stora hus（大车们/大房子们） |
| 定式形（单/复数定式） | 修饰任何定式名词（有 den/det/de 前缀时） | 通常加 -a | den stora bilen / det stora huset（那辆/座大...） |

> *💡 记忆诀窍：只有 ett词不定单数 需要加 -t；其余所有需要变化的情况（复数、定式）统一加 -a。两个规则覆盖了绝大多数情况。*
>
> *💡 与德语对比：德语形容词变格需要考虑四个格（主/宾/与/属）加三个性（阳/阴/中）共12种组合。瑞典语只有上述四种形式，大幅简化。英语形容词完全不变。*

### ② 完整变格示例（stor / liten / gammal）

|  |  |  |  |  |
|----|----|----|----|----|
|  | **en词不定单数** | **ett词不定单数** | **复数不定** | **定式（单/复数）** |
| stor（大） | en stor bil | ett stort hus | stora bilar | den/det stora bilen/huset |
| liten（小） | en liten katt | ett litet barn | sma djur \* | den/det lilla katten/barnet \* |
| gammal（老/旧） | en gammal man | ett gammalt hus | gamla manniskor | den/det gamla mannen/huset |
| ny（新） | en ny bok | ett nytt rum | nya bocker | den/det nya boken/rummet |
| rod（红色） | en rod blomma | ett rott apple | roda blommor | den/det roda blomman/applet |

> *⚠️ liten（小）是最重要的不规则形容词：ett词形式是 litet（不是 \*litet），复数是 sma（完全不规则），定式是 lilla（单数）或 sma（复数）。必须单独记忆。*
>
> *⚠️ gammal（老）的 ett词形式是 gammalt，复数是 gamla——注意双写 l 消失。类似的形容词（词根以 -al/-el/-en/-er 结尾）在加 -t/-a 时常有拼写调整。*

### ③ 定式结构：den/det/de + 定式形容词 + 定式名词

当名词前有形容词时，需要同时使用前置定冠词（den/det/de）和后置定冠词后缀，形容词本身使用定式（-a形式）：

|  |  |  |
|----|----|----|
| **名词类型** | **结构** | **示例** |
| en词 单数定式 | den + 形容词(-a) + 名词(-en) | den stora bilen（那辆大车） |
| ett词 单数定式 | det + 形容词(-a) + 名词(-et) | det gamla huset（那座旧房子） |
| 复数定式 | de + 形容词(-a) + 名词(-na/-en) | de nya bilarna（那些新车） |

> **Den stora bilen ar rod.**
>
> (那辆大车是红色的。 / *The big car is red.*)
>
> *-\> den + stora（定式-a）+ bilen（定式后缀-en）*
>
> **Jag gillar det gamla huset.**
>
> (我喜欢那座旧房子。 / *I like the old house.*)
>
> *-\> det + gamla（定式-a）+ huset（定式后缀-et）*
>
> **De sma barnen sover.**
>
> (那些小孩子们在睡觉。 / *The small children are sleeping.*)
>
> *-\> de + sma（liten 不规则复数/定式）+ barnen*
>
> *💡 第一章提到过：单独的名词用后缀定冠词（bilen），但名词前有形容词时换用前置 den/det/de。这两套系统不能混用：不能说 \*stora bilen（缺 den），也不能说 \*den stor bilen（缺 -a）。*

### ④ 谓语形容词（系动词后的形容词）

形容词作谓语（放在 vara/bli 等系动词后）时，规则与不定式修饰名词相同——按名词的 genus 和数变化，但不加定式 -a：

> **Bilen ar stor.**
>
> (车很大。 / *The car is big.*)
>
> *-\> bilen 是 en词，谓语形容词用基本形 stor*
>
> **Huset ar stort.**
>
> (房子很大。 / *The house is big.*)
>
> *-\> huset 是 ett词，谓语形容词加 -t: stort*
>
> **Bilarna ar stora.**
>
> (这些车很大。 / *The cars are big.*)
>
> *-\> 复数谓语形容词加 -a: stora*
>
> *💡 简单规则：谓语位置的形容词只需判断 en词/ett词/复数，用对应的基本形/中性形/复数形即可，不需要定式 -a。*

## 3.2 颜色词汇

颜色形容词遵循上述变格规则。下表给出每个颜色词的四种核心形式，以及作为名词使用时的形式（"红色"这个颜色本身）：

|  |  |  |  |  |
|----|----|----|----|----|
| **中文** | **基本形（en词）** | **中性形（ett词）** | **复数/定式** | **颜色名词** |
| 红 | rod | rott | roda | rott (ett rott) |
| 蓝 | bla | blatt | bla | blatt (ett blatt) |
| gron（绿） | gron | gront | grona | gront |
| 黄 | gul | gult | gula | gult |
| 橙 | orange | orange（不变） | orange（不变） | orange（不变） |
| 紫 | lila | lila（不变） | lila（不变） | lila |
| 粉 | rosa | rosa（不变） | rosa（不变） | rosa |
| 白 | vit | vitt | vita | vitt |
| 黑 | svart | svart（不变） | svarta | svart |
| 灰 | gra | gratt | gra | gratt |
| 棕/褐 | brun | brunt | bruna | brunt |
| 浅蓝 | ljusbla | ljusblatt | ljusbla | — |
| 深蓝 | morkbla | morkblatt | morkbla | — |

> *借自法语/英语的颜色词（orange, lila, rosa, beige, turkos）在瑞典语中通常不变格——所有形式相同。这类外来词是固定形式的常见规律。*
>
> *bla（蓝）的复数/定式形式也是 bla（不是 \*blaa），但 ett词形式是 blatt。gra（灰）同理。这些以 -a 结尾的颜色词复数不再加 -a。*

### 颜色例句

> **Hon har en rod jacka och bla byxor.**
>
> (她穿一件红色外套和蓝色裤子。 / *She has a red jacket and blue trousers.*)
>
> *-\> rod (en词), bla (复数不变)*
>
> **Det grona huset ar vackert.**
>
> (那座绿色的房子很漂亮。 / *The green house is beautiful.*)
>
> *-\> det grona huset：定式结构，det + grona + huset*
>
> **Vad heter den fargen pa svenska?**
>
> (那种颜色瑞典语怎么说？ / *What is that colour called in Swedish?*)
>
> **Himlen ar gratt idag.**
>
> (今天天空是灰色的。 / *The sky is grey today.*)
>
> *-\> gratt：ett词谓语形容词（himmel 是 en词，但 det ar gratt = it is grey，det 是中性泛指）*

### 情绪表达句式

描述自己或他人的情绪有几种固定句式：

- vara + 情绪形容词（最直接）：Jag ar glad.（我很高兴。）

- kanna sig + 情绪形容词（感觉/感到）：Jag kanner mig trott.（我感觉很累。）

- bli + 情绪形容词（变得/感到——强调变化）：Hon blev forvanad.（她感到惊讶。）

- verka + 情绪形容词（看起来）：Han verkar stressad.（他看起来很有压力。）

> **Jag kanner mig verkligen lycklig idag.**
>
> (今天我真的感到很幸福。 / *I feel really happy today.*)
>
> *-\> kanna sig + lycklig（en词谓语形容词）*
>
> **Varfor ar du sa ledsen?**
>
> (你为什么这么难过？ / *Why are you so sad?*)
>
> *-\> sa（如此）+ 情绪形容词，加强程度*
>
> **Barnen verkar hungriga.**
>
> (孩子们看起来很饿。 / *The children look hungry.*)
>
> *-\> hungriga：复数形式（-a）*

## 3.4 喜好与偏好表达

表达喜好是日常对话的核心功能之一。瑞典语有几个层次的喜好动词，从强烈到一般：

|  |  |  |  |
|----|----|----|----|
| **动词/表达** | **程度** | **用法** | **英文对应** |
| alska | 最强（爱） | alska + 名词/att + 不定式 | to love |
| tycka om | 喜欢（普通） | tycka om + 名词/att + 不定式 | to like |
| gilla | 喜欢（口语，较随意） | gilla + 名词/att + 不定式 | to like (colloquial) |
| foredraga | 更喜欢（对比偏好） | foredraga + 名词 / ...framfor... | to prefer |
| bry sig om | 在乎/关心 | bry sig om + 名词 | to care about |
| hata | 讨厌（最强负面） | hata + 名词/att + 不定式 | to hate |
| inte tycka om | 不喜欢 | inte tycka om + 名词 | to dislike |
| vara likgiltig for | 对...无所谓 | vara likgiltig for + 名词 | to be indifferent to |

### 喜好句型详解

tycka om 是最常用的喜好动词，注意它是可分动词（tycka ... om），在句中有时被其他成分分隔：

> **Jag tycker om musik.**
>
> (我喜欢音乐。 / *I like music.*)
>
> *-\> tycka om + 名词（直接宾语）*
>
> **Tycker du om att laga mat?**
>
> (你喜欢做饭吗？ / *Do you like cooking?*)
>
> *-\> tycka om + att + 不定式：喜欢做某事*
>
> **Jag alskare att resa.**
>
> (我热爱旅行。 / *I love travelling.*)
>
> *-\> alska + att + 不定式*
>
> **Han foredrager te framfor kaffe.**
>
> (他比起咖啡更喜欢茶。 / *He prefers tea to coffee.*)
>
> *-\> foredrager ... framfor ...（A比起B更喜欢）*
>
> **Jag gillar inte regnvadar.**
>
> (我不喜欢下雨天。 / *I don't like rainy weather.*)
>
> *-\> gilla（口语）+ inte*

### 程度副词

以下程度副词与形容词/喜好动词搭配，表达不同强度：

|  |  |  |  |  |
|----|----|----|----|----|
| **副词** | **程度** | **中文** | **英文** | **示例** |
| valdigt / jattet | 极强（口语） | 非常/超级 | very / super | jattet roligt（超好玩） |
| mycket | 强 | 很 | very / much | mycket bra（很好） |
| ganska | 中等 | 相当/挺 | quite / rather | ganska trott（挺累的） |
| lite | 弱 | 有点/稍微 | a bit / slightly | lite hungrig（有点饿） |
| inte alls | 完全否定 | 一点都不 | not at all | inte alls glad（一点都不高兴） |
| alldeles for | 过度（否定意味） | 太/过于 | way too | alldeles for dyrt（太贵了） |

## 3.6 比较级与最高级

瑞典语的比较级和最高级有规则变化和不规则变化两套系统，规律上与英语高度对应（-er/-est 或 more/most）。

### ① 规则变化：-are / -ast

大多数形容词通过加后缀构成比较级和最高级：

|  |  |  |  |
|----|----|----|----|
| **原级（en词形）** | **比较级（+ -are）** | **最高级（+ -ast）** | **含义** |
| stor | storre \* | storst | 大/更大/最大 |
| lang | langre \* | langst | 长/更长/最长 |
| ung | yngre \* | yngst | 年轻/更年轻/最年轻 |
| gammal | aldre \* | aldst | 老/更老/最老 |
| snabb | snabbare | snabbast | 快/更快/最快 |
| billig | billigare | billigast | 便宜/更便宜/最便宜 |
| trevlig | trevligare | trevligast | 好/更好/最好 |
| intressant | intressantare | intressantast | 有趣/更有趣/最有趣 |

> *💡 单音节形容词（stor, ung, lang 等）常有元音变换（umlaut）：stor→storre, ung→yngre, gammal→aldre——类似德语比较级的元音变音规律（alt→alter vs. alter）。*

### ② 不规则变化（必须记忆）

|          |            |            |                        |                       |
|----------|------------|------------|------------------------|-----------------------|
| **原级** | **比较级** | **最高级** | **含义**               | **英语类比**          |
| bra      | battre     | bast       | 好/更好/最好           | good / better / best  |
| dalig    | samre      | samst      | 差/更差/最差           | bad / worse / worst   |
| manga    | fler       | flest      | 多（可数）/更多/最多   | many / more / most    |
| mycket   | mer        | mest       | 多（不可数）/更多/最多 | much / more / most    |
| liten    | mindre     | minst      | 小/更小/最小           | little / less / least |
| gammal   | aldre      | aldst      | 老/更老/最老           | old / older / oldest  |

### ③ 比较句型

比较级配合以下句型使用：

- A ar + 比较级 + an B（A比B更...）

- A ar lika + 原级 + som B（A和B一样...）

- A ar inte sa + 原级 + som B（A没有B那么...）

- den/det + 最高级 + -a（最...的那个）

> **Det har huset ar storre an det dar.**
>
> (这座房子比那座大。 / *This house is bigger than that one.*)
>
> *-\> storre（比较级）+ an（than）*
>
> **Hon ar lika gammal som jag.**
>
> (她和我一样大。 / *She is the same age as me.*)
>
> *-\> lika ... som = as ... as*
>
> **Det ar den basta filmen jag har sett.**
>
> (这是我看过最好的电影。 / *It's the best film I've ever seen.*)
>
> *-\> den basta（最高级定式）+ filmen*
>
> **Battre sent an aldrig!**
>
> (迟到总比不到好！ / *Better late than never!*)
>
> *-\> battre（比较级）+ an*

## 综合短文：一篇人物介绍

*体裁：第三人称描述性短文 · 场景：介绍一位朋友 · 难度：A2*

本篇短文综合运用本章所学的形容词变格（谓语/定语位置）、颜色词汇、情绪词汇、喜好表达和比较级，在自然的人物介绍语境中展示形容词的多种用法。

**— 短文正文 —**

> **Min basta van heter Maja.**
>
> (我最好的朋友叫Maja。 / *My best friend is called Maja.*)
>
> **Hon ar tjugosex ar gammal och bor i en liten lagenhet i centrala Stockholm.**
>
> (她二十六岁，住在斯德哥尔摩市中心一套小公寓里。 / *She is twenty-six years old and lives in a small apartment in central Stockholm.*)
>
> **Maja ar lang och smal, med kortt, morktt har och stora, bruna ogon.**
>
> (Maja又高又苗条，留着一头短短的深色头发，长着一双大大的棕色眼睛。 / *Maja is tall and slim, with short, dark hair and big, brown eyes.*)
>
> **Hon brukar klä sig i enkla, rena kläder — ofta i marinbla eller svart.**
>
> (她通常穿着简单干净的衣服——常常是深蓝色或黑色的。 / *She usually dresses in simple, clean clothes — often in navy blue or black.*)
>
> **Maja ar en av de snallaste och roligaste personerna jag kanner.**
>
> (Maja是我认识的最善良也最有趣的人之一。 / *Maja is one of the kindest and most fun people I know.*)
>
> **Hon ar alltid lugn, till och med nar livet ar stressigt.**
>
> (她总是很平静，即使在生活紧张的时候也是如此。 / *She is always calm, even when life is stressful.*)
>
> **Maja tycker mycket om att lasa — hon laser minst en bok i veckan.**
>
> (Maja非常喜欢读书——她每周至少读一本书。 / *Maja loves reading — she reads at least one book a week.*)
>
> **Hon alskare ocksa att laga mat och brukar bjuda in vanner pa middag varje manad.**
>
> (她也热爱烹饪，每个月都会邀请朋友来吃晚饭。 / *She also loves cooking and usually invites friends for dinner every month.*)
>
> **Maten hon lagar ar alltid vacker och god — battre an pa manga restauranger!**
>
> (她做的菜总是既好看又好吃——比很多餐厅还强！ / *The food she makes is always beautiful and delicious — better than at many restaurants!*)
>
> **Nar Maja ar ledsen eller trott, lyssnar hon pa musik.**
>
> (当Maja感到难过或疲倦时，她会听音乐。 / *When Maja is sad or tired, she listens to music.*)
>
> **Det verkar hjalpa — hon blir alltid gladare efterat.**
>
> (这似乎很管用——她之后总是变得更开心。 / *It seems to help — she always becomes happier afterwards.*)
>
> **Jag ar valdigt tacksam att ha en sa god van.**
>
> (我非常感激能有这样一个好朋友。 / *I am very grateful to have such a good friend.*)

**语法标注**

|  |  |
|----|----|
| **短文片段** | **语法说明** |
| Min basta van | basta = bra 的最高级定式（-a），basta van：定式结构（无需 den，因为 min 已有限定功能） |
| en liten lagenhet | liten（en词形）修饰 en词 lagenhet；不定单数，用基本形 liten |
| lang och smal, med kortt, morkt har | lang/smal：en词谓语形容词（基本形）；kortt har：ett词不定单数（-t形式）；morkt：同上 |
| stora, bruna ogon | 复数不定形容词：stora（-a）/ bruna（-a）修饰复数名词 ogon |
| en av de snallaste och roligaste | 最高级 + 定式 -a（snallaste / roligaste）；de = 复数定冠词 |
| battre an pa manga restauranger | battre = bra 的比较级（不规则）；an = than；manga（很多）+ 复数名词 |
| Hon blir alltid gladare efterat | gladare = glad 的比较级（规则，-are）；bli + 形容词 = 变得… |
| en sa god van | sa（such a / so）+ 原级 god（bra 的同义词）；注意 bra 和 god 的区别：bra 泛指，god 多指人品/味道 |
